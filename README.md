# 課題0505 リファクタリング

`main.c` は **0 以上 10 未満ではないとき「OK」，そうでないとき「NG」** を表示する，動作するプログラムである．

## 課題
**動作を変えずに** 次のように書き直せ(リファクタリング)．
1. 否定演算子 `!` を使わない(`!=` は使ってよい)．
2. `else` を使わない(`if` だけで書く)．

ヒント: `!(A && B)` は「A でない または B でない」と同じ意味である(ド・モルガンの法則)．
`else` を使わないときは，OK になる場合と NG になる場合を，それぞれ別の `if` で書く．

## 提出するファイル
- `main.c`
- `ai_log.txt`

## 採点について
- push すると GitHub Actions が自動採点します。結果は Actions のログと、フィードバック用の Pull Request に出ます。
- 採点は **プログラムを実行した結果** で行います。何度でも push して再採点できます。
- `ai_log.txt`(AI利用ログ)も採点対象です(10点)。AIを使ってもかまいません。ただし **AIの答えを自分で確かめること** が課題の目的です。
